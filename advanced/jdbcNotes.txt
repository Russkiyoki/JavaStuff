in jdbcStuff.java, we learned how to make a connection, but it is also good to know
how to use that connection with CRUD operations. In order to use CRUD operations in 
a java application, you need to import additional interfaces such as

	import java.sql.Statement; // contains static sql statements
	import java.sql.PreparedStatement; // Stores compiled SQL statement
	import java.sql.ResultSet; // Stores the result of the SQL Statements

In previous courses, we learned why using "?" is important for our queries.
It is important because it creates multiple safety nets and moments for
our db to look for mistakes or things that are very stupid by user or
even for someone with a malicious intent to sql-inject.
