/* some issues with awt is that it is not consistent across all systems
   thus creating issues. Swing aims to fix those, it is an improvement
   to awt and it provides us with lightweight components, platform
   independent tools, and more customizable appearance */

import javax.swing.*;
public class SwingExample {
	public static void main (String[] args) {
		// create a frame
		JFrame frame = new JFrame("Swing Example");
		JButton button = new JButto("Click the Button");
		frame.add(button);
		frame.setSize(250,430);
		// close application when window is closed
		frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
		frame.setVisible(true);
	}
}

/* layout managers:
   BoxLayout: Restrictive layout manager that allows multiple components to be 
   laid out either vertically or horizontally. Does not allow any form 
   of wrapping.

   GroupLayout: Works with vertical and horizontal layouts differently, and 
   each dimension is defined independently. Each component needs to be defined
   twice within the layout.

   ScrollPaneLayout: two scrollbars, a row header, a column header, a viewport,
   and four corner components.

   SpringLayout: Flexible layout manager that allows precise relationships
   between edges of components under its control. Used by GUI Builders. 

*/
